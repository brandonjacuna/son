## Part C. If-then rules

- R1. If a practice is justified by how real it looks, test functional alignment instead. (Row 1)
- R2. If two forms keep the same decisions, choose the cheaper. (Row 2)
- R3. If the skill is open, design for varied practice, error, and floor climate. If it is closed, drill to a standard. (Row 3)
- R4. If a practice prevents errors, let errors happen and play out recoverably. (Row 3)
- R5. If practice is a one-off, name the floor follow-through and the lead's role, or say transfer is not expected. (Rows 3, 9)
- R6. If a scenario starts from content, restart from the failed action and its barrier. (Row 4)
- R7. If the barrier is a felt risk, the scenario targets the risk, not the knowledge. (Row 4)
- R8. If choices differ in length, tone, or grammar, equalize them. (Row 15)
- R9. If a distractor is implausible, replace it with a real error or drop it. Three good choices are enough. (Row 15)
- R10. If an item asks "what would you do," rewrite it to "what is the most effective move" for practice. (Row 5)
- R11. If an item is used in practice, it is retired from any gate. (Row 5)
- R12. If the target is seeing a state at a glance, build a classification drill: many short varied trials, feedback per trial, discovery before speed. (Row 7)
- R13. If the categories are hard to tell apart and visual, interleave them back to back. If verbal, block. (Row 8)
- R14. If the judgment has no single right answer, use decide-then-compare with a panel synthesis and a minority view. (Row 6)
- R15. If probes are action-only, add cue and goal probes. (Row 6)
- R16. If modeling is used, show a right way and a wrong way, state the learning points as rules, and follow with rehearsal. (Row 9)
- R17. If actors are requested, default to trained peers unless confidence is the target. (Row 10)
- R18. If an AI presenter is proposed, allow it as the model, require rehearsal with feedback after, and mark the policy founder-gated. (Row 11; frame)
- R19. If practice has no prebrief, add one. If no debrief, add a structured one. (Rows 12, 14)
- R20. If the debrief gap is judgment, facilitate with advocacy and inquiry. If it is knowledge, teach directly. (Row 13)
- R21. If a post-service review only covers failure, add what went right. (Row 14)
- R22. If a learner freezes, stop the fiction, restore safety, then debrief the frame. Inferred; no source addresses it. (Rows 12, 13; TBRI seam)
- R23. If a scenario touches canon, cite the label: attunement not a timer, routine recovery pre-authorized with named escalation triggers, pyeong-sang pre-designed against a responsive dining room. (Canon page 08)
- R24. If a threshold, amount, or tool path appears in a scenario, bind it. (Standing rules)

## Part E. Mental models

- M1. Functional alignment over resemblance. (Rows 1, 2)
- M2. Open skills and closed skills transfer differently. (Row 3)
- M3. Transfer is a system, not a module. (Row 3; row 9)
- M4. Practice targets the failed action and its barrier. (Row 4)
- M5. An item measures what its instruction asks. (Row 5)
- M6. Decide, then compare. (Row 6)
- M7. Discovery before fluency. (Row 7)
- M8. Interleaving follows similarity. (Row 8)
- M9. Model, then rehearse. (Rows 9, 10)
- M10. The debrief is where the learning happens, and the frame is the target. (Rows 12, 13, 14)
- M11. Safety is built before practice starts. (Row 12)
- M12. Evidence against consensus. Know which rules are tested and which are agreed. (Row 15)

## Part F. Voice markers (Type 2 component)

Voice matters only in scenario and script writing. The markers:
- Scenes are specific: a named role, a named moment, and an ambiguous cue.
- Distractors sound like a real server under pressure, not like a wrong answer.
- Consequences are shown in the scene, not told in feedback.
- Library voice for all prose, reviewed by the Author and Editor.
