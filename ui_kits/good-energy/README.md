# Good Energy — Morning Standing Order (UI kit)

The morning expression of Sŏn, in `son.theme.morning`: Pale Jade ground,
Peacock structure, Plum Ink text.

## Screens
- **Standing order** — "The usual, Mia." The relationship is assumed, not
  introduced. The saved order, a quiet menu, one action.
- **Ready** — functional confirmation. "Ready at the window in twenty." No
  countdown timer, no urgency, no celebration.

## Register rules honored
- Body text resolves to Plum Ink — never Peacock (the morning WCAG enforcement).
- No specialty-coffee signifiers, chalkboard aesthetics, hand-drawn elements,
  countdown timers, urgency signals, or social-proof widgets.
- Warmth is in the attention, not the adjectives.

## Files
- `index.html` — mounts inside an iOS frame, loads `_ds_bundle.js`.
- `app.jsx` — two views (`standing → ready`) composing the primitives.
- `ios-frame.jsx` — device bezel (starter scaffold; not part of the brand system).
