A hairline text field. Label rides above in the eyebrow register; the field is an underline, not a box.

```jsx
<Input label="Name on the table" placeholder="Mia" />
<Input label="Party size" error="Tables seat up to six." />
```

Props: `label` · `error` (specific, not apologetic) · `hint` · all native input props. The bundled `.son-field` CSS supplies hover/focus.
