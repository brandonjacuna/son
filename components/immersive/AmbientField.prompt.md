# AmbientField

A slow-moving flat-color ground that keeps a section subtly alive. One flat panel of the theme's secondary surface drifts over the primary surface. No gradient, no texture overlay, ever.

- glyph renders the 선 glyph at large scale in slow motion. This is a deliberate canon override (the readme fixes the glyph at constant scale), gated behind --son-glyph-motion: set it to off on any scope to remove the module without touching anything else.
- Static under prefers-reduced-motion.
