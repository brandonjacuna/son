The action primitive. Primary fills, secondary outlines in a hairline, ghost is type alone. No drop shadows; near-square corners.

```jsx
<Button variant="primary">Reserve a table</Button>
<Button variant="secondary">View the menu</Button>
<Button variant="ghost" size="sm">Cancel</Button>
```

Variants: `primary` · `secondary` · `ghost`. Sizes: `sm` · `md` · `lg`. Supports `disabled`, `fullWidth`, and all native button props. Hover/press handled via the bundled `.son-btn` CSS.
