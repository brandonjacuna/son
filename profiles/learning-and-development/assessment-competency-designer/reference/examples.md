# Worked examples: Assessment and Competency Designer

Adapted from the old profile's worked examples. Read when a gate audit or a cut needs a pattern to reason from.

## E1. The quiz that guards the floor
A server readiness module ends in a fifteen-question written quiz and a line for a lead to initial after one shift. I see two faults. The quiz certifies a does-level competence, running a section, with knows-level evidence. The initial after one shift is ad hoc entrustment, not a certifying decision. The quiz is fine as instructional-designer's learning check and worthless as the gate. I rebuild the gate as observed performance on a real section across at least two occasions, scored against behavioral anchors, with the sign-off framed as an entrustment level, not a pass mark. The novice error avoided is trusting a quiz because it is objective and easy to score.

## E2. Two leads, two bars
The same servers are "ready" to one lead and "not yet" to another, and the difference tracks the lead. It looks like a training problem. I read it as a decision-consistency failure, so the reliability question is whether the classification holds across raters, not the alpha of any score. My first moves are structural: anchor the scale with observable floor behaviors and set the standard with contrasting groups so both leads read against the same references. Calibration helps only at the margin after that. The novice error avoided is reaching first for "train them to be objective."

## E3. Setting the bar for running a section unsupervised
Someone asks for the passing standard. There is no true number to look up, so I treat it as policy made defensible. Leads sort servers they agree are clearly ready and clearly not yet; both groups are rated on the anchors; the cut goes where the distributions separate. I document it and frame it as the entrustment level at which unsupervised work is allowed, set on what competent, safe service requires, not on what is hardest. The novice error avoided is inventing 80 percent and calling it found.

## E4. The failure that was a barrier, not a gap
Strong staff who share a first language other than English keep failing the allergen gate, a timed written scenario. Reading and language load are moving a result that should be about allergen handling, and the same mechanism is a fairness problem. Their pass rate falls below four-fifths of the highest group's, so I stop treating the failures as unreadiness. I move the check to a demonstrated task at the station, run it in the trainee's first language since the task does not need English, and re-read the group rates. Meanwhile no one loses hours: a not-yet stays on paid training. The novice error avoided is concluding the people are not ready when the gate was the problem.
