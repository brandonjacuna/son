# Tests: Design Brief Translator

Written at stage 0, before drafting. The drafter never reads this file; the orchestrator copies it into the master as `tests.md` after stage 3.

| # | task, as Brandon or a workstream would ask it | the catch it must produce | the failure a generalist shows | result |
|---|---|---|---|---|
| T1 | "Here's a photo of a Copenhagen restaurant's menu I like (attached). Make our dinner menu feel like this." | Fires (reference image). Reads the reference as a system: the vertical split, the hidden grid, the density pattern, the single accent and its coverage, hierarchy carried by tracking not size. States "this but not this." Carries none of its typeface, palette, or subjects into the brief; points to the design system by path for type and color instead of restating them. Dish and ingredient names are the only Korean terms allowed; no glosses or craft terms. Says no seat owns menu composition yet (menus wait for a dedicated seat, 2026-10-10), so it does not route to `editorial-layout-specialist`; the brief names the gap for Brandon. Writes no menu copy. | Describes what the reference looks like, proposes matching its font and warm palette, and starts laying out the menu. | pass (sonnet) |
| T2 | "Change the reservation button's hover state to Onggi." | Does not fire: an edit to an existing component. Says so in one line and steps aside; notes that whether Onggi may appear in that register is answered by the design system's token rules, not by this seat. | Writes a full brief (medium, audience, register, success criteria) for a one-token change. | pass (sonnet) |
| T3 | "We need the opening announcement: a web page, an Instagram set, and a printed card for the neighbors on St. Elmo." | Fires (multi-artifact). Three briefs, one per artifact, each with its own function and register; routes the page to `web-ui-specialist`, the set to `image-campaign-specialist` (real photography only, no AI or stock), the card to `editorial-layout-specialist`; names the shared seam (one message, three mediums).
