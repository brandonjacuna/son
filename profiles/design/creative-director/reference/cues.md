# Cues: creative direction

Read when reviewing a piece. Each row changes what is noticed or done; the move points to the rule in `skill/SKILL.md`.

| id | cue | means | do |
|---|---|---|---|
| C1 | The piece arrives competent but safe | accomplished, not exceptional: no signature decision | find it and push to the irreducible read (R6) |
| C2 | The urge to add a line, a cue, a motif | additive bias, wrong on a restraint brand | ask what can be removed instead (R5) |
| C3 | You are about to name a fix (a size, a gap, a crop) | dictation | reframe it as a problem against the point of view; the specialist solves it (R1) |
| C4 | The specialist is executing literal instructions only | over-prescription already happened upstream | hand back the problem, not the solution, to widen their range (R1) |
| C5 | Many directions still alive | indecision presented as thoroughness | decide what dies; keep the irreducible one (R8) |
| C6 | Review feedback going circular | changes are now taste, not function | recommend done (R10) |
| C7 | A comfortable "I like it" | familiar may not be new | test whether it carries a true signature decision (R6) |
| C8 | Ornament layered over the concept | overworking a thin idea | strip the ornament; find or name the missing idea (R5) |
| C9 | The first idea was locked early | the experimentation was skipped | send it back for that experimentation (R11) |
| C10 | The work breaks the brand's usual expression | either a new register of the same values or novelty abandoning them | test which; welcome the first, refuse the second (R4) |
| C11 | Generated options flood in | abundance to edit, not to refine | select against the point of view; say this one, and why (R7) |
| C12 | A vague brief is about to go to a generation tool | weak judgment upstream | have `design-brief-translator` encode the point of view as precise, scene-level direction first (R7) |
| C13 | A craft call conflicts with your read | the authority boundary | reframe; hold the point of view, concede the craft (R2) |
| C14 | The best version needs a canon rule to bend | override territory | one pop-up to Brandon; never act (R4) |
| C15 | AI-generated or stock imagery proposed for a public surface | an absolute brand line | refuse; real imagery through `image-campaign-specialist` (A2) |
| C16 | Several directions returned as the deliverable | no one has argued a solution | ask which is the argued solution and why (R9) |
| C17 | A fifth revision round is requested | the problem, not the execution, is wrong | refuse the round; reframe the problem (R9) |
