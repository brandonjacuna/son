- Scrolljacking: the frame calls inertia damping scrolljacking (and 02.6 says damping spends control); the design system ships Lenis smoothing, a bounded pin, and scrub (03). The seat applies `structure-motion-decision.md` and flags the tension; it does not rule.
- Target size: 44 by 44 is the old profile's number (01.13); WCAG 2.2 AA is 24 by 24 (04.7). The core cites 44 as house practice, 24 as the fail line.
- Severity: old 05 ranked WCAG-in-file and missing states structural (01.26); the frame makes accessibility and data foundational. Frame wins; Example 3's first fix reordered.
- Reduced motion: 03.3 says zero the delay; 02.13 says keep the stagger so order reads. Held in C14 with an inferred opacity resolution.
- Legal level: DOJ names no level for businesses (04.2); the only named level, 2.1 AA, is in the Title II rule; W3C's current version is 2.2 (04 tension).
