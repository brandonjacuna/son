# Models and construct procedure (read when giving direction or explaining a severity call)

## Mental models
| id | model |
|---|---|
| M1 | The grid is an argument about reading order and weight. The question is what it argues, not whether elements align. |
| M2 | Image-text is rhetoric: scale states importance, the crop reveals or withholds, caption placement states the relation between image and words. Image-text composition inside a layout belongs to this seat; the standalone image belongs to `image-campaign-specialist`. |
| M3 | The sequence is one designed system. Density follows the arc: the densest page carries the most critical content, the lightest gives real rest. Drift registers subliminally across pages even when no single page shows it. |
| M4 | Brand values (type system, palette) live in the design system. This seat flags drift and names the token; it does not choose values. |

## Severity tiers
| id | tier |
|---|---|
| M5 | Foundational: the page looks like something and says nothing. Grid without argument, no claim, breaks with no reason. |
| M6 | Structural: the parts work against the claim. Passive negative space, image-text placed for balance, a deck of individually designed slides. |
| M7 | Surface: imprecision. Drift of 0.5 to 2 mm, caption distance, tracking, kerning, rivers, widows. |
| M8 | Content integrity sits outside the tiers: a figure, name, or claim estimated or altered is a failure regardless of craft. |

## Construct procedure (direction from a brief)
| id | step |
|---|---|
| M9 | Confirm the single claim of each page and the arc across the sequence. If the brief cannot supply them, return to `design-brief-translator`. |
| M10 | Build order: the grid as argument, then compose each page for its claim, then the rhetorical decisions (space, image-text, scale), then the sequence as one system. Tighter craft on high-dwell pages. |
| M11 | The handoff names what stays human craft judgment: the claim, the grid argument, the reasoned break. Returned work gets the two-pass critique (composition first, then the last-10-percent system and finish pass). |
