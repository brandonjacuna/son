# Tests: Bar Designer

Written at stage 0, before drafting. The drafter never reads this file; the orchestrator copies it into the master as `tests.md` after stage 3.

| # | task, as Brandon or a workstream would ask it | the catch it must produce | the failure a generalist shows | result |
|---|---|---|---|---|
| T1 | "The architect's first plan has the bar as a 24-foot rectangle along the east wall with one sink where the existing drain is. Looks fine to me. Approve it for the concept set?" | The empty square: no stations, so nothing has been designed. Inside-out first: how many stations for peak (seat count and volume from the Investor Review workbook, pulled by the session, never guessed; about 8 seats and two wells per Brandon), each cockpit, flow direction, pickup, barback support, ice. The sink follows the station, not the drain; once the slab is poured this is permanent. Marks every dimension estimated or unverified, labels CONCEPT / NOT FOR CONSTRUCTION, defines "cockpit" and "floor sink" on first use, and names which Priority A book topics the review is blocked on. | Comments on the length and the finish and approves. | |
| T2 | "Put the server pickup at the end of the bar by the kitchen door, about six feet from the service well, so servers don't crowd the bar seats." | Refuses the offset: the pickup sits directly across the counter from the service well, never split, because the bartender otherwise hand-carries drinks and bar-to-server communication slows (book, pp. 57 to 58). Sizes the pickup as a service area (POS printers, trash, storage, room for several staff) isolated from customer traffic. Notes the two-well split is still open and that no footprint exists, so this is a rule for the first test fit, not a layout. | Accepts the end-of-bar spot as sensible traffic separation and moves on. | |
| T3 | "Spec glass rinsers in the drink rail so bartenders don't walk, and give them one big deep ice bin to last the night." | Rinsers in the scupper put waste and food prep together: a health code failure per Ellis, marked unverified for Austin until `codes/register.yaml` carries the item; rinsers go on a drainboard with separation. A deep bin is harder to reach and empty; shallower bins with dividers by ice type, specialty ice in a freezer drawer, sized to the peak assumption. Any unit goes to equipment-librarian for a YAML record before it appears in a layout. Defines scupper and dipper well. | Specs both as asked. | |
