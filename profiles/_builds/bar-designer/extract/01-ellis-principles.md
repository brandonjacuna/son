## Rows
| id | kind | row | quote | locator |
|---|---|---|---|---|
| 01.1 | cue | Bar shown as an empty square in plan set -> bar not designed -> stop, design stations first -> run inside-out before finishes | "the bar stays an empty square" | s1, ellis-public [2] |
| 01.2 | rule | If slab/drains/MEP are not poured, let station layout drive floor sinks and power; because no one core-drills a new build to move a station | "no one will core-drill a new build" | s1, ellis-public [4] |
| 01.3 | rule | Design machinery (purpose, function) before the aesthetic wrap; because the engine must fit the body | "you do not design a car body and hope the engine fits" | s1, ellis-public [2] |
| 01.4 | rule | Aesthetic and operational teams work in lockstep with one translator between them | | s1, ellis-public [2] |
| 01.5 | cue | Bartender walks behind the bar -> non-value time -> zero-step violated -> pull the item into reach | "non-value time" | s1, ellis-public [3] |
| 01.6 | model | Hospitality happens in the gaps between steps; fewer steps free time for the customer. Training cannot fix a 20 ft walk per drink | | s1, ellis-public [4] |
| 01.7 | rule | Size for the peak hour with every seat full, not the average; a station can be closed on a slow night, not added later | | s1, ellis-public [3], perlick-training [13] |
| 01.8 | rule | Duplicate stations, never mirror; mirroring puts expensive bottles in the left hand and reverses clean-to-dirty | | s2, perlick-training [13] |
| 01.9 | rule | Flow left to right, clean to dirty; spirits to dominant (right) hand, mixers, soda gun, garnish left; top base spirits in front row | | s2, perlick-training [13] |
| 01.10 | anti | Double speed rail; pushes hips-to-drink-rail out and forces a lean. Use one rail plus tiered steps | | s2, perlick-training [13] |
| 01.11 | anti | Glass rinser in the scupper rail; health code violation, food prep and waste need physical separation | "a health code violation everywhere he has worked" | s2, ellis-public [4] |
| 01.12 | anti | Deeper, bigger ice chests; harder to reach and empty. Specialty ice gets its own freezer, dividers for ice types | | s2, perlick-training [13] |
| 01.13 | decision | Custom fabrication vs catalog / why hard: looks bespoke / novice error: ignores 3x to 8x cost and NSF-approved shop requirement | | s2, ellis-public [4] |
| 01.14 | decision | Contractors place equipment at existing drains; the specifier is rarely the user, so have a bar-service operator review | | s1, ellis-public [4] |
| 01.15 | rule | Design real barback space (restock path, support section), not just bartender stations | | s4, derived |
