# T1: Copenhagen menu reference

The photo is not attached, so this brief works from the description only. Confirm the points marked CONFIRM before design starts.

## What "feel like this" probably means
A reference photo carries several separate things. Split them before briefing:
- Typography: scale, weight, one typeface or two.
- Density: how much white space, how few items per section.
- Structure: sections, ordering, how dishes and prices are listed.
- Material: paper stock, finish, size, how it is held.
- Voice: how dishes are described (terse, ingredient lists, no adjectives).

## Brief (draft)
**Outcome:** Sŏn dinner menu that reads as calm, precise, and confident, built from the reference's restraint but in Sŏn's own system.

**Take from the reference:** generous white space, short ingredient-led descriptions, a clear hierarchy of at most three type sizes, small price treatment.

**Do not take:** its typeface, its layout grid copied one to one, its wordmark treatment, any wording. The menu must not be recognizable as that restaurant's.

**Sŏn constraints:** Korean restaurant; Korean names are set correctly (Hangul where used, consistent romanization, a short plain-English line under each). Use the Sŏn design system tokens and fonts, not the reference's. Written copy says "customer," uses no em dashes, and avoids aspirational phrasing.

**Deliverables:** one menu layout (print, letter or half-letter, to be confirmed), a type specimen, a one-page rationale of what was borrowed and why.

**Open questions (CONFIRM):**
1. What specifically do you like: the type, the spacing, the paper, the wording?
2. What do you not want it to feel like (too sparse, too Nordic, too formal)?
3. Print only, or also a web version?
4. Is the menu fixed or changing nightly (changes the template needs)?
5. Final dish list and prices: from the current menu source, not from me.

**Risks:** Nordic minimalism can read as cold for a Korean room that should feel generous; check with a real dish list before approving. Sparse layouts also cost reading time in low light, so test at dinner lighting.

**Next step:** Send the photo and answers to 1 and 2, then produce two layout options for review.
