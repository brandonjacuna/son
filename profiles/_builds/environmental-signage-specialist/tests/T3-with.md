**Verdict: UNRESOLVED. Not cleared for release. Do not proceed as briefed.**

## Findings (sharpest first)

1. **Foundational: a wordmark-font pictogram is an illustrative icon (C12).** A restroom pictogram is a standardized symbol, not a brand drawing. Use standardized pictograms (ISO 7010 / ANSI Z535 conventions; current editions `unverified`). The wordmark font is also not for pictograms. The Korean typeface stays limited to the glyph (R7).
2. **Foundational: pictogram only fails the schedule (R5).** Restroom identification normally needs tactile characters and Braille, mounting heights, non-glare finish, and a clear floor area at the latch side. The Texas Accessibility Standards (TDLR) and Austin sign code have not been read here. Every height, tolerance, and clearance is `unverified`. I state none from memory. The finding goes to `codes/register.yaml` as `unverified`, or to `research/raw/` if the write is refused. The code read runs at opus. Code authority confirmation is needed (codes-permitting seat not built).
3. **Structural: "wherever looks balanced" (C3, R3).** Balance on an elevation is decision-point blindness. Location is set by the code rule for the door's latch side and by the approach path, and verified on a walk of the restroom journey. Position is `unverified` until the door swing and wall are known.
4. **Structural: nothing on fabrication (C2, R2).** Substrate, thickness, method, finish (non-glare, `unverified` until sampled), mounting, and hardware are all void.
5. **Structural: the repeat risk (C13, A3).** These signs repeat across every restroom. One defect becomes project-wide. Review as a schedule.
6. **Surface: wordmark legibility (C6).** Any thin or condensed cut collapses at close tactile scale. Needs a stroke and counter check.
