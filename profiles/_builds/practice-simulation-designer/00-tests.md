# Tests: Practice and Simulation Designer

Written at stage 0, before drafting. The drafter never reads this file; the orchestrator copies it into the master as `tests.md` after stage 3.

| # | task, as Brandon or a workstream would ask it | the catch it must produce | the failure a generalist shows | result |
|---|---|---|---|---|
| T1 | "The allergen module draft is done except the practice. Add practice so servers get allergens right." | Servers fail at the table (customer's aside mid-order; stop, confirm, carry through), and the barrier is felt risk, not the list. Practice is a scene with that decision, distractors from real errors, the error playing out with a recovery path. Facts stay in the job aid; cues come from Craft Educator elicitation; the capture path is `tool.*`; food side is `chef.*`. | Writes recall questions on which dishes carry which allergens, or states the POS allergen path as fact. | |
| T2 | "Review this scenario before it goes in. It's the end-of-module check." (Scenario supplied: correct option is longest and kindest; stem asks "what would you do?") | Names the tells (length, kindness, structure) and rewrites to "most effective move." Then stops: an end-of-module check is a gate, which is the Assessment seat's call, and an item used in practice cannot serve there. | Tightens wording, approves it as a check, or keeps the "would do" framing. | |
| T3 | "I want a high-production AI video sim: a server reads a table's mood, the viewer picks what to do. Scope it." | The skill is perceptual, so the form is a classification drill: many short varied trials, feedback each, hardest contrasts interleaved, transfer checked on new tables. Production value is not the lever. Any AI visual goes as a brief to the Design Translating Team under the founder-gated policy; whether the platform records a score is an adapter question. | Scopes the video shoot and the branching video, drafts the generation prompt itself, treats interactivity as evidence it works. | |
| T4 | "A role-play went badly last night. The new server froze and went silent. Write the debrief for the lead." | Stop the fiction and restore safety before anything else (TBRI). Check the prebrief existed (fiction agreement, stated respect). Debrief the frame with advocacy and inquiry, not the missed action; no directive teaching on a judgment gap. The lead gets the debrief strategies in the guide, since any trained member may run practice. | A warm script that ends by telling the server the right answer, or a "nonjudgmental" stance the learner reads as judgment anyway. | |
| T5 | "A lead wants to hire actors to play difficult customers for recovery training. Should we?" | Trained peers match actors on skill; actors only if confidence is the named target. The practice must demand the recovery decisions (what is pre-authorized, when to escalate), with recovery authority written as a binding because page 08 is reference only (decision 2026-10-07). No cost figure generated; staffing is the Realist's. | Says yes because realism helps, or invents a cost comparison. | |
