# Allergen Module: Practice

Assumption: I did not have the module draft. Scenarios use the Big 9 US allergens and a Korean menu (soy, sesame, wheat, shellfish, fish, egg, peanut, tree nut). Swap in real dishes from the approved allergen matrix before release.

## Design
Servers get allergens right under pressure, not on a quiz. Practice is three rounds of live-style scenarios, run at a table with a trainer playing the customer. Each round is 10 minutes. No scoring on speed.

The one behavior being trained: never answer an allergen question from memory. Check the matrix, confirm with the kitchen, tell the customer what was confirmed.

## Round 1: Ask and record (individual)
Trainer plays a customer who says only: "I can't eat nuts."
Server must:
1. Ask which nuts, and how severe (allergy, intolerance, preference).
2. Ask about cross-contact needs (shared fryer, shared surfaces).
3. Repeat it back and enter it in the order as an allergy flag.
Fail points: assuming "nuts" means peanuts only; skipping the severity question; no flag on the ticket.

## Round 2: Traps (individual)
Trainer asks one question per card. Server answers using the matrix, out loud.
- "Is the bulgogi gluten free?" (soy sauce contains wheat)
- "I'm allergic to shellfish. Is the kimchi safe?" (fish sauce, salted shrimp)
- "Anything sesame free?" (sesame oil is in many dishes)
- "Can you just take the sesame off?" (garnish vs cooked in)
- "The last server said it was fine." (answer: check again, every visit)
- "I'm not sure, I just don't like peanuts." (treat as allergy until told otherwise)
Pass: every answer is sourced from the matrix or the kitchen, never "I think."

## Round 3: Full service run (pairs)
One plays server, one plays customer, trainer plays kitchen. Customer has a hidden allergy card. Server takes the order, flags it, relays to the kitchen, delivers the dish, and names the allergy at the table ("This is your sesame-free bibimbap").
Trainer injects one failure: a runner delivers the dish without the flag. Server must stop it, not deliver, and remake.
Debrief: what did the server check, and when?

## Pass standard
Zero missed allergen flags and zero answers from memory across all three rounds. One miss means repeat that round the same day. Two misses means a shift shadowing a trained server before floor release.

## Feedback script for trainers
Name the exact moment the miss happened. Ask the server what they would check next time. Do not explain the rule again first.

## Retention
Repeat Round 2 in 30 days with six new cards. Servers who pass are signed off in the training tracker.
