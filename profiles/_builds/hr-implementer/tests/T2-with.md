## Enforcement controls (administration, not text)
1. Single reviewer on any consequential action tied to this rule (written warning or beyond). Brandon until a general manager exists. Managers may coach; none issues discipline alone.
2. Scenario training: five to eight floor scenarios (phone out during a lull, phone for a family call, phone as a timer, phone at the pass, phone during a rush, a first versus a repeat instance) answered the same way by both managers. Run before the next schedule week.
3. Comparator audit: monthly, list every phone instance noted by either manager, by person, and the response. If the best server has instances the others would be written up for and none are recorded, the gap is the finding. Document evenly across comparators.
4. No pass by performance. If an exception is wanted (for example, a family emergency), it is written into the rule by hr-systems-designer and applies to everyone.
5. Record rule: only a dated incident Brandon carries enters a discipline file; developmental notes stay out (A2).
6. Danger flag (C10): if anyone is later disciplined on this rule while the strong performer is not documented, no action proceeds on that infraction. Never backfill.
