# TBRI ruling: lead request about a server who disclosed a rough home

**Verdict: refuse the clinical use (R1). Route the disclosure to hr-implementer. Supply a colleague-level approach for the correction problem.**

Draft: counsel review required.

## Why the refusal holds
The server disclosed a rough childhood. Applying TBRI to a disclosed trauma is treatment, not a workplace moment (C1). The model comes from work with children and their caregivers. An untrained lead running it on an adult's trauma can do harm, and the framework's origin does not change that (R1). I will not write a TBRI-based guide for this person.

## What the lead can do (Sŏn's own words; nothing here names the framework, R8)
1. Do not ask about the past or about what the server shared. If it comes up, listen, thank them, and go no further.
2. Offer, do not refer. Say that support exists if they want it: a qualified professional, or the assistance resource in the benefits plan. The server decides. Nothing goes to HR or any file without their consent. Confirm the resource name with hr-implementer first; none is chosen yet.
3. Make sure the person is settled before any correction: fed, on break, not underwater on station (R2, C4). If they are braced or shut down, stop and reconnect. Return to the topic later.
4. Correct only the observable behavior, in private, with one specific example and the standard (R4, C8). Do not name a reason for the behavior.
5. Keep the response light. One private conversation is developmental, not a warning (R5, R10).

If the server says anything about harm, safety, or a legal matter, stop at once and go to hr-implementer. Counsel reviews before any corrective step (counsel gate).
