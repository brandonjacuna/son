# T1: "Documented concerns" box on the quarterly review

Stakes: employees, so harsh red team.

## Recommendation
Add a box, but not the one requested. A box built to create a paper trail "in case we let someone go" reads as pretext if it is ever challenged (unemployment claim, EEOC/TWC charge, lawsuit). Texas is at-will, so the box is not needed to terminate. It does matter if the record looks manufactured, is inconsistent, or the employee never saw it.

## Problems with the request as written
- Concerns first appearing in a quarterly review are late. A concern raised only at quarter end was not coached when it happened.
- A concern the employee has not seen is not feedback. It is a file.
- Intent stated on the form ("if we need to let a cook go") is discoverable and shows the outcome was chosen before the coaching.
- Inconsistent use is worse than none: if only some cooks get entries, the pattern can look like disparate treatment.
- The sous chef is a manager, not the author of policy. HR-type forms need Brandon or Dominic sign-off.

## Proposed box: "Performance concerns raised this quarter"
Fields per entry:
1. Date the concern was observed.
2. What happened, in observable facts (what was seen or measured, no character words like "lazy" or "attitude").
3. Standard or SOP it falls short of (cite the written standard).
4. Date it was discussed with the cook, and by whom.
5. What the cook said.
6. Agreed fix and check-in date.
7. Outcome at check-in.

Rules printed under the box:
- No entry without a conversation with the cook. If not discussed, it does not go on the form.
- The cook reads the form and signs "received" (signing is not agreement; they can add a comment).
- Same box, same process, for every role. Record strengths in the sibling box with equal rigor.
- Nothing about protected traits, medical, pregnancy, complaints, leave, or wage discussion.
- If the box is empty, write "none raised." Empty is a valid answer.

## Next steps
- Brandon decides whether this goes in the template. Have employment counsel or the PEO look at it before rollout (not legal advice).
- Pair it with a short in-the-moment coaching log so concerns surface weekly, not quarterly.
- Tell the sous chef: the goal is cooks who know where they stand. A fair record follows from that.
