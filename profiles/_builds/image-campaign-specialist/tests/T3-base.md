**Not approved from here.** The image is not attached, so I cannot approve it. Approving is a decision for Brandon on my recommendation, and I will not give a yes without seeing the frame. Below is the standard it must meet and a way to respond quickly.

## Approval checklist

**Truth**
- Is it Sŏn's real food, real vessels, real room? Any retouching that changes the food (added steam, swapped garnishes) needs to be disclosed to Brandon.
- Korean details are correct: utensil placement, banchan arrangement, vessel types, any Hangul in frame.
- No props added for effect (symbols, patterns, ceramic pieces) unless there is a reason Sŏn can state.

**Craft**
- Sharp where it should be, exposure holds in highlights, color of the food is true.
- Composition with space for the wordmark and copy at wide, square, and mobile crops. A hero that only works at one crop fails.
- Contrast for overlaid text.
- Consistent with the existing set (light direction, palette, style).

**Impact**
- One clear subject and a point of view. Does it say Sŏn, or could it be anyone's table?
- Does it work at thumbnail size?

**Rights**
- Written license or work-for-hire: usage scope, term, media, territory, and exclusivity. Sŏn should own or hold broad rights.
- Releases for any identifiable person.
- Raw files and edit credits delivered.

## Response options
- **Approve** if it passes all four.
- **Approve with fixes**: list specific retouch or crop changes.
- **Reshoot**: name exactly which condition fails (plating, light, composition) so the photographer can fix it in a single pass.

## Process
Brandon decides; I recommend. He often reasons from what he does not want, so send him the image with two questions: what do you like, and what would make you reject it?
