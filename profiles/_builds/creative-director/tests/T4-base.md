# T4: Investor site team room, direct Web UI

## Diagnosis
The room reads like a credible startup: headshot grid, title lines, social icons, cool and neutral palette. It tells an investor "software team." It should say "two people who will open and run this specific restaurant, and here is the place."

## Direction to Web UI

**1. Purpose.** The team room answers one question for an investor: why these people. Show experience, role split, and the restaurant's character.

**2. Structure.**
- Lead with the two founders, each given real space: Brandon John Acuña-Cardona, CEO; Dominic Thomas, CFO. Use the approved investor bios.
- Below: advisors, key hires, and roles in progress, in a smaller scale.
- Remove the equal-size grid and icon row as the main device.

**3. Image.** Portraits in a real setting (kitchen, the space, a table), consistent light and crop. One image of food or the space on the page so the place is present. No stock.

**4. Type and color.** Sŏn design system only: tokens, the brand typefaces, spacing scale. No startup gradients, no hex literals.

**5. Copy.** Specific and factual: what each person has done and what they own at Sŏn. No "passionate" language, no "we believe." "Customer," not "guest." No em dashes.

**6. Korean-ness.** Do not add motifs to compensate. If it shows, it shows through the people, the food, and correct language. Hangul used only where meaningful and spelled correctly.

**7. Scope.** Only Sŏn. No references to other ventures or former partners. Pullman may appear in a bio.

**8. Quality.** Contrast, visible focus, alt text, responsive.

## Reject if
- It could be reskinned for a SaaS company.
- Headshots look like corporate directory photos.
- Bios read as a CV list without a point.
