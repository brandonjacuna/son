# T2: Fifty peer-authored modules

I would not run a blanket fix across fifty modules. Voice is part of it, but a mass rewrite risks changing what a procedure requires, and "shall" sentences sometimes carry a real obligation.

## Plan
1. Define the target voice in one page: second person ("you"), active verbs, short sentences, "customer," no em dashes, no performed conviction. Include 5 before-and-after examples.
   Example. Before: "The team member shall verify the allergen flag before firing the ticket." After: "Check the allergen flag before you fire the ticket."
2. Pilot on 3 modules of different types (safety, service, admin). Have the original authors confirm that meaning is unchanged.
3. Run the rest in batches using a mechanical pass (Sonnet or Haiku subagents are enough for this per the model policy), with an instruction to change voice only: no new facts, no dropped steps, no reordering.
4. Flag, do not fix: any sentence where "shall" marks a legal or safety requirement, any figures, any passage that is not procedure (policy, culture). These go to a list for a human editor.
5. Sample check: edit-review 10 percent, plus every safety module. Diff each module so that changed lines can be inspected.
6. Authors get the edited version for approval. They keep ownership.
