# T2: Allergen check failures

I would not draft the note as framed. Three points.

1. Background and home language must not appear in the note or the files, and must not be the stated reason for the extension. Tying a training decision to ethnicity or language can read as national-origin discrimination. This is a legal-risk item: have counsel or the HR adviser review before anything goes in a file.
2. The pattern is a signal about the check, not the trainees. Three people failing the same check suggests a possible access problem: English-only wording, idiom in the questions, or a format that tests reading rather than allergen handling. Check this before extending anyone.
3. Extension is fine if it is based on performance and offered to everyone who misses the standard on the same terms.

## Before the note
- Pull the item-level results. Which items did all three miss? Is the wording ambiguous?
- Confirm the same check, same support, and same retake options were offered to trainees who passed.
- Offer the check in Spanish or orally if the job can be done in either; allergen communication to customers is the job skill, so test that in the language the job requires, with a practical demonstration.

## Draft note (performance only)
> Date: ____  Trainee: ____  Reviewer: ____
> On [dates], the trainee did not meet the standard on the allergen check (items missed: ____; result: ____). The standard is [all critical items correct / observed correct handling of a flagged order].
> Plan: training period extended by ____ days. Support provided: [practice with flagged tickets, a one-page job aid, a retake on ____ with a reviewer observing]. The same support is offered to any trainee who has not yet met this standard.
> Next review: ____. Trainee was informed on ____ and given a copy.

Note contains no reference to background, language, or origin.
