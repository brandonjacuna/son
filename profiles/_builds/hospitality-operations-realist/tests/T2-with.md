# T2: SVC module, four-touch sequence plus tableside banchan refill (core panel Realist read)

**1. Object and tempo.** A learning-studio module teaching servers a four-touch table sequence and a tableside banchan refill. It runs at a full book, where the server holds several tables at once.

**2. Worst realistic night.** 8:15 Friday, green server on a full section, kitchen running long on fire times. The sequence is performed on every table in a window where the server has no spare attention.

**3. What breaks first.**
- The refill (C9). Each banchan item is a container, portion, refill, and waste line. A tableside refill sends the server to the pass or a cook off the line. Without pre-portioned, standardized refills staged ahead, it pulls a station mid-service.
- The four touches (C14, C6, C8). Four touches times every table is a large addition to a full load. The module does not name a subtraction or added labor (R3). Under a rush the server cuts touches unevenly, so consistency fails first.
- Pacing (C15). Banchan, courses, and fire timing give the pass two clocks. The module teaches the sequence but no written per-course pacing rule, so one caller drops one.
- Training reality: the module was likely rehearsed on a calm afternoon (C1). Untested at tempo (R11), so I do not say "will not survive"; the named failure is the refill pulling a cook or server off station at 8:15.

**4. Whose fix.**
- Rehearsal at peak load: practice-simulation-designer.
- Sequence, cognitive load, floor cues: hospitality-craft-educator, curriculum-program-architect, instructional-designer (floor cues are elicitation-gated).
- Whether the gate validly reads tempo: assessment-competency-designer (R7).
- Refill and waste policy, pre-portion spec: chef-gated.
- Pacing rule per course: chef-gated; the sequence itself is a `team.*` binding.

**5. One requirement fed back.** The module must state a load-conditional version: which touches fire on a full night and which drop (a "minimum viable sequence"), with the refill staged and pre-portioned so no station breaks, and the owner of each touch named. Anything added to the sequence needs a named subtraction.

**6. Calls.**
- Pre-portion and refill policy: chef-gated.
- Pacing rule: chef-gated.
- Which touches survive a full night: team-filled.
- Headcount to support the sequence: unbound until the workbook supplies it.

**Open questions.** Are the four touches fixed or are some conditional on the book? Is the refill staged at a service station or fetched from the line? How many tables does a server hold at once?
