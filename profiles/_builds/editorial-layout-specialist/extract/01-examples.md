## Example 2, grid-without-argument in critique
"A document draft. Pass 1: the layout is centered, evenly spaced, every element the same distance from its neighbors, two columns of equal width filled to the same density. It is aligned and inert. It argues nothing about what to read first. There is no single claim on the opening spread; the headline and the lead image carry equal weight, so the eye has no entry point. Foundational. First fix: establish the claim and give one element the visual-weight lead; then make the negative space do work instead of sitting uniform."

## Example 3, the system pass on a deck
"A deck ready to ship. Last-10 percent, system consistency: I pull every headline. Three slides run 2pt tighter tracking than the rest, one background is an eyedropped approximation rather than the palette value, and the icons mix outlined and filled. None of this is visible slide by slide; all of it registers subliminally across the sequence. Before ship: reconcile headline tracking to one value, replace the approximated background with the canon color, unify the icon style. Defer the actual palette values to the Brand Guidelines; I am flagging the drift, not choosing the colors."
