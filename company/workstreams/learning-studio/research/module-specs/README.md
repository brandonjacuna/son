# Module specs

Each file is one module group from `research/module-discovery-2026-09.md`, rewritten so every module says what it teaches: who it is for, what a person can do after it, three to six specific teaching points with sources, what it leaves to other modules, how it is proven, what it waits on, and a keep, merge, or cut recommendation. No module content is written; these are specifications. The research fields from discovery are kept alongside.

The same data is loaded into the Module Review page (claude.ai artifact QRu1evLAawnFdqaBh6XxdQ), where Brandon marks each module keep, cut, change, or question.

Pilot (2026-10-01): the trunk, groups 3.1a, 3.1b, 3.1c.
