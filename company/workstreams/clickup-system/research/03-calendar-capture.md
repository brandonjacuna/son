# Calendar + Meeting Capture Pipeline — Research Brief

Prepared 2026-09-16 for Sŏn (ClickUp workspace 90131574430, Business + AI add-on, Google Calendar connected).

## Key findings

1. **CONFIRMED** — ClickUp's calendar surface is now called the **Planner** (built on the newer "Calendar" app), and it can create events with guests, a video-call link (Zoom, Teams, **Google Meet**, or SyncUp), and a **location** field that syncs to the connected external calendar. [ClickUp Help](https://help.clickup.com/hc/en-us/articles/35975552416023-Create-events-and-schedule-meetings-from-your-Planner)
2. **CONFIRMED** — Google Calendar two-way sync is a distinct, older feature from the Planner's native event creation: it syncs **tasks** (title, start/due date) to Google Calendar and back, not full Google Meet/guest-rich events. Set-up must be repeated separately for each direction (ClickUp→Google and Google→ClickUp). [ClickUp Help](https://help.clickup.com/hc/en-us/articles/6336507264663-Google-Calendar-Syncing)
3. **CONFIRMED — real limitation:** tasks synced to Google Calendar require a start **or** due date; tasks with no date, or a due date in the past, do not sync. [ClickUp Help](https://help.clickup.com/hc/en-us/articles/6336507264663-Google-Calendar-Syncing)
4. **CONFIRMED — real limitation:** ClickUp task→Google sync only works to a **personal** Google Calendar, not a shared/team calendar. [ClickUp Help](https://help.clickup.com/hc/en-us/articles/6336507264663-Google-Calendar-Syncing)
5. **CONFIRMED — long-standing gap:** recurring ClickUp tasks show only their **current instance** on Google Calendar; future recurring instances do not push through. Users have flagged this as unresolved for 5+ years in ClickUp's feedback forum. [ClickUp Feedback: Show future recurring tasks on Google calendar](https://feedback.clickup.com/feature-requests/p/show-future-recurring-tasks-on-google-calendar)
6. **CONFIRMED:** Google Calendar events created directly in Google do **not** create ClickUp tasks — sync is asymmetric in that respect (Planner events are separate from this task-sync feature and do round-trip as events). [ClickUp Help](https://help.clickup.com/hc/en-us/articles/6336507264663-Google-Calendar-Syncing)
7. **CONFIRMED:** No dedicated calendar/events endpoint exists in the public ClickUp API (v2, `api.clickup.com/api/v2`); "add calendar to API" is an open feature request, not shipped. Programmatic meeting scheduling means creating a **recurring task** via the API (which the Planner then surfaces/syncs), not calling a calendar-events API directly. [ClickUp Canny: Add calendar to API](https://clickup.canny.io/public-api/p/add-calendar-to-api), [ClickUp API docs](https://developer.clickup.com/)
8. **CONFIRMED:** ClickUp AI Notetaker joins ad hoc or scheduled Zoom/Google Meet/Teams meetings, records, and produces a private Doc (summary, key takeaways, action items, transcript). Requires Planner connected to Google/Outlook Calendar; for Zoom, the host must pre-enable "auto-approve" settings. [ClickUp Help](https://help.clickup.com/hc/en-us/articles/28928137493015-Use-AI-Notetaker-to-take-notes-and-record-meetings)
9. **UNCERTAIN/no built-in feature:** there is no native "rolling 4-week meeting creation" mechanism. Closest built-ins are (a) ClickUp recurring tasks (daily/weekly/monthly/custom, but see #5's Google-sync gap) or (b) scheduled automation (Zapier/n8n "schedule" trigger, or the ClickUp API + a cron job) that creates a task/event N weeks out on a schedule. [Zapier: create weekly ClickUp tasks from scheduled triggers](https://zapier.com/apps/clickup/integrations/schedule/1210957/create-weekly-clickup-tasks-from-scheduled-triggers)
10. **CONFIRMED:** Granola has **no native ClickUp integration**. The ClickUp↔Granola connection runs through **Zapier only** — "note added to folder" can trigger a ClickUp task or a new ClickUp Doc page. [Zapier: Granola × ClickUp](https://zapier.com/apps/granola/integrations/clickup), [Zapier: create ClickUp doc pages from Granola notes](https://zapier.com/apps/clickup/integrations/granola/255674629/create-new-clickup-document-pages-from-newly-added-notes-in-granola-folder)
11. **CONFIRMED:** Granola ships a public **API** and an official **MCP server** (launched ~Feb 2026), both gated to the **Business plan ($14/user/month)**; native app integrations (Slack, Notion, HubSpot, Affinity, Attio) are separately configured, also Business+. **No webhooks yet** — Granola confirms webhooks are "on the roadmap," so any automated push to ClickUp today means polling the API/Zapier trigger, not event-driven push. [Scalekit: Granola MCP vs API](https://www.scalekit.com/blog/granola-mcp-vs-api), [Granola integrations guide](https://www.granola.ai/blog/granola-integrations-complete-guide-connecting-meeting-tools)
12. **CONFIRMED:** Granola's iPhone phone-call feature supports **outbound calls only** — inbound calls cannot be transcribed "due to strict limitations in iOS." A founder calling in would need to be the one placing the call, or the pipeline works only for calls they initiate. [Granola Docs](https://docs.granola.ai/help-center/ios/phone-calls)
13. **CONFIRMED — real limitation:** only one phone number can be registered per Granola account at a time, and setup requires a verification call that can be blocked by spam filters; some carriers (e.g., Telstra in Australia) are blocked outright. No U.S.-specific carrier issue was found, but the single-number and verification friction is real. [Granola Docs](https://docs.granola.ai/help-center/ios/phone-calls)
14. **UNCERTAIN:** no direct evidence of iPhone audio/recording-quality complaints specific to Granola's phone-call feature; App Store reviews instead cite **UI friction** (missed-call notification handling, ~1-second speakerphone-toggle lag). Broader transcription-accuracy complaints (90-92% accuracy, degraded on accents/cross-talk/background noise/5+ participants) are about meeting transcription generally, not phone calls specifically, and are largely from unverified review-blog sources rather than Granola or Apple. [tl;dv Granola review](https://tldv.io/blog/granola-review/)
15. **CONFIRMED alternative for a 2-person founder phone standup:** a dedicated hardware/software recorder independent of iOS's inbound-call restriction — e.g., **Plaud Note** (physical device, ~30hr battery, speaker ID, works for in-person or phone audio via device mic) — sidesteps Granola's outbound-only limitation. For a scheduled recurring call, doing it as a **Google Meet/Zoom call instead of a cellular phone call** and sending ClickUp AI Notetaker or Granola's desktop app would also avoid the inbound-call gap entirely. [Spinach AI: best meeting recorders 2026](https://www.spinach.ai/blog/best-meeting-recorders-for-teams), [eesel AI: Plaud alternatives](https://www.eesel.ai/blog/plaud-ai-alternatives)

## Detailed notes

### ClickUp Calendar/Planner + Google Calendar
- The **Planner** (help section "ClickUp Planner") is ClickUp's newer unified scheduling surface — it shows tasks, time blocks, and connected external-calendar events together, and lets you create/join meetings directly. [ClickUp Help: What is the Planner?](https://help.clickup.com/hc/en-us/articles/29051586233879-Use-the-Planner-to-schedule-tasks-and-meetings)
- Creating an **event** (not a task) from the Planner supports: title, date/time, **location** (physical address, room, etc. — syncs to the external calendar), a **video-call provider** (Zoom/Teams/Google Meet/SyncUp — ClickUp auto-generates the join link), and **Add participants** (search/select workspace members or external emails), which sends calendar invites. [ClickUp Help](https://help.clickup.com/hc/en-us/articles/35975552416023-Create-events-and-schedule-meetings-from-your-Planner)
- Separately, the **Google Calendar Syncing** feature (older, task-centric) pushes ClickUp **tasks'** title/start/due date to a personal Google Calendar and back; it is not the same pipeline as Planner-native events, and it explicitly does not sync guests/Meet links — it syncs the task's basic scheduling fields. Confirm which of the two mechanisms (Planner event vs. task-sync) your recurring meetings should use before building the Super Agent, since they have different guest/Meet/location capabilities and different failure modes (see gotchas).
- Recurring **events** created via the Planner are effectively built on recurring **tasks** under the hood per ClickUp's own docs ("create a recurring task for each recurring meeting"), which is why the recurring-task Google-sync gap (future instances not pushed) likely also constrains recurring Planner events pushed via the older sync path — this needs hands-on verification in the live workspace before relying on it.

### ClickUp API
- Public API is v2 (`api.clickup.com/api/v2`); machine-readable index at `developer.clickup.com/llms.txt`. No calendar/events resource exists — task creation/update is the only lever. A rolling 4-week meeting-creation Super Agent will need to create/update **tasks** (with assignees, dates, and probably a custom field or description carrying the agenda + Meet link) via the API/MCP tools already available in this session (`clickup_create_task`, etc.), then rely on Planner/Google sync — or on directly creating Google Calendar events via the **Google Calendar API** in parallel — for the actual calendar invite delivery. [ClickUp API docs](https://developer.clickup.com/)
- Because ClickUp's native task→Google sync has the past-due-date and future-recurring-instance gaps (#3, #5), a more reliable rolling-4-week design is likely: an external scheduler (Zapier/n8n/cron + Google Calendar API or Apps Script) creates the actual Google Calendar event directly (with Meet link + guests), and separately creates/links a ClickUp task via API for tracking — rather than depending on ClickUp's calendar sync to produce the invite.

### Granola
- Plans: native integrations (Slack, Notion, HubSpot, Affinity, Attio) and the MCP server both require **Business plan, $14/user/month**. Zapier is available on paid plans generally. [Granola integrations guide](https://www.granola.ai/blog/granola-integrations-complete-guide-connecting-meeting-tools)
- Notion integration exports notes as **database entries** (not flat pages), enabling filters/properties — a pattern worth mirroring if piping into ClickUp Docs (i.e., push into a structured ClickUp Doc/task rather than freeform text).
- No native ClickUp connector exists; **Zapier "New Note in Folder" → Create ClickUp Task/Doc Page** is the documented path today. Since Granola has no webhooks, Zapier's Granola triggers are polling-based, meaning some delay (typically minutes) between a Granola note finishing and it landing in ClickUp — not instant. [Granola × ClickUp Zapier](https://zapier.com/apps/granola/integrations/clickup)
- Folders are Granola's main organizational unit for routing automations (Slack auto-post, Zapier triggers) — so a "Sŏn Meetings" Granola folder convention would let a single Zap fan out to ClickUp consistently.
- The Granola MCP server (per-user, Feb 2026 launch) could let a Claude/agent workflow pull meeting notes/transcripts directly rather than going through Zapier, but it's gated to Business plan and is per-user (not a workspace-wide bot), per Scalekit's comparison. [Scalekit](https://www.scalekit.com/blog/granola-mcp-vs-api)

### Phone-call capture (2-person founder standup)
- Granola iPhone: **outbound only**, single phone number per account, requires phone verification (can be blocked by spam filters), works in 50+ countries. No inbound support is a hard iOS platform restriction, not a Granola product gap — same restriction would apply to most competitors doing on-device capture. [Granola Docs](https://docs.granola.ai/help-center/ios/phone-calls)
- Practical implication: whichever founder **places** the call (not the one who receives it) needs Granola open/registered on their phone; the workflow must be "Brandon calls Dominic," not either-direction, or must move to a Meet/Zoom-based call instead of native cellular.

## Gotchas / limits

- Planner-native events (with Meet link + guests) and legacy Google-Calendar task-sync are **two different ClickUp features** with different capabilities — don't assume the "recurring tasks sync to Google" docs also describe Meet-link/guest behavior; verify directly in the Sŏn workspace.
- Tasks with no date, or a past due date, silently fail to sync to Google Calendar.
- Recurring task → Google Calendar sync shows only the current instance; future instances are not visible on Google Calendar (5+ year open complaint).
- Task→Google sync only targets a **personal** calendar — not usable for a shared/team calendar out of the box.
- Google-created events do not create ClickUp tasks (one-way for that specific sync path).
- No ClickUp API endpoint for calendar events — plan the Super Agent around task creation + Planner/Google sync, or a parallel direct Google Calendar API call.
- Granola has no webhooks — anything "automatic" out of Granola today is Zapier-polling or MCP-pull, not push; expect a few minutes of lag.
- Granola phone calls: outbound-only, one number per account, Business-plan gating for API/MCP/native integrations.
- Several of the "quality issue" and accuracy-percentage claims found in search (90-92% accuracy, accent/cross-talk degradation) come from third-party review/marketing blogs, not Granola or verified first-hand reports — treat as UNCERTAIN/directional, not confirmed fact.

## Implications for Sŏn

- **Don't rely on ClickUp's task→Google sync to deliver the actual meeting invite** for the rolling-4-week recurring meetings — its date/past-date/future-recurring-instance gaps make it fragile for a "remote by default, invites go out reliably" requirement. Prefer the Planner's native event creation (guests + Google Meet + location, invites sent directly) or a direct Google Calendar API call from the Super Agent, with a linked ClickUp task for tracking/agenda/notes.
- **Build the Meetings Super Agent around ClickUp task/API creation + direct Google Calendar API for the invite**, since no ClickUp calendar-events API exists yet. This also sidesteps the recurring-instance sync gap.
- **Granola → ClickUp is Zapier-only today**; budget for that middle layer (folder-based routing: one "Sŏn Meetings" Granola folder → Zapier → ClickUp Doc page under the relevant meeting task) rather than expecting a native or webhook-driven connection. Revisit if Granola ships webhooks or a native ClickUp integration later.
- **For the 2-person founder phone standup**, either (a) have the calling founder use Granola's outbound-call feature (accepting the outbound-only constraint and single-number-per-account limit), or (b) skip cellular entirely and run the standup as a Google Meet call captured by ClickUp AI Notetaker or Granola's desktop app — more reliable and consistent with the "remote by default" meeting policy already planned.
- Since Granola's native/MCP/API features require the **Business plan ($14/user/month)**, confirm Granola plan tier for all three founders before designing the pipeline around API/MCP/native integrations.
- Verify hands-on in the live Sŏn workspace whether Planner-created recurring events actually deliver Google Meet invites to attendees reliably before wiring the Super Agent — documentation confirms the capability exists, but the recurring-task sync caveats suggest real-world testing is warranted before depending on it for weekly operations.
