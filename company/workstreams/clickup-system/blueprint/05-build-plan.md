## Rollback principles

1. Nothing is deleted until its replacement is verified and, where a gate exists, signed. Archive beats delete.
2. The Stage 0 baseline is the restore source for every value-level change; keep it read-only.
3. Field/status/type *definitions* are only removed once `clickup_filter_tasks` proves zero populated values.
4. Each agent trigger has its own off switch; roll back one rung at a time, never the whole agent.
5. Any accidental touch of a protected task is logged in DECISIONS.md the same day, with the restored value.
