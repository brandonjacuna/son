# Prototype agenda templates (verbatim structure, instance text removed)

## Weekly Founders Sync
- Header: meeting name, date/time, reschedule note if moved
- Summary from last Thursday Standup (links to that record)
- Calendar event instance ID; join link
- Previous meeting summary (link)
- ## Open items
- ## Blockers / risks
- ## Decisions needed
- ## Upcoming items
- ## <Founder name>: @mention, "add topics, notes, blockers, decisions, questions" (one section per founder)
- ## Live notes and summary
  - ### Key decisions
  - ### Action items (owner, action, due date)
  - ### Parking lot / follow-ups
- Footer: prep reminder schedule

## Founders Thursday Standup
- Header + parent series link
- Calendar mapping (instance ID, series link, "Timing source of truth: Google Calendar")
- ## Updates / progress
- ## Risks / blockers
- ## Decisions needed
- ## Upcoming priorities
- ## <Founder name> sections (@mention)
- ## Live notes and summary
  - ### Key decisions
  - ### Risks / blockers
  - ### Action items ("Clear follow-ups become separate tasks in Founding Punch List")
  - ### Parking lot / follow-ups ("revisit in next Weekly Founders Sync")
