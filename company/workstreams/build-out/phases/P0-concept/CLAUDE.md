# P0 Concept rules

No lease is signed. Everything here is concept work for thinking through constraints, custom work, and equipment fit before real drawings exist.

- Assume nothing about the final space. If a design depends on the site, write the assumption at the top of the file (for example "assumes 207 E St. Elmo Rd, ceiling height unknown").
- Work in a sandbox branch unless Brandon asks to update a canonical design.
- Every drawing, model, and export carries "CONCEPT / NOT FOR CONSTRUCTION" and a date.
- No ClickUp tasks from here except capture-list ideas or a real action Brandon commits to.
- Areas: bar, kitchen, live-fire, mep, lighting, av-network, storage, water. Each area folder holds a `README.md` (current direction, constraints, open questions) plus concept files.
- Live fire is the largest cost and space driver. Treat exhaust routing, make-up air, and AHJ approval as constraints on every layout, not afterthoughts.
