International Fire Code and Local Amendments Effective July 10, 2025, the City of Austin adopted the 2024 edition of the International Fire Code with local amendments. Austin Fire is revising and updating the Fire Protection Criteria Manual through the City’s rule making process. When the revision is completed, a link to the updated manual will be provided. In the interim, the 2012 Fire Protection Criteria Manual can still be used for guidance in the application of the 2024 International Fire Code (IFC) and Local Amendments . For information on the Wildland Urban Interface Code please visit Austin Fire’s Wildland-Urban Interface Code website.
Fire Protection Criteria Manual In an effort to make the application of codes and standards more predictable, the City of Austin has developed a series of technical interpretation manuals that include a manual of interpretations and guidance for fire code application. Use the index in the left column (green background) to navigate within the Fire Criteria Manual.
