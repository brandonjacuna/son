# Stage 1 corpus: Practice and Simulation Designer

This corpus grounds the seat's judgment: which practice form transfers for a given skill, and how consequence, feedback, fidelity, and debrief are designed so rehearsal carries to the floor. Every row grounds at least one decision the seat makes. Nothing here is a survey of the field.

Build date 2026-09-26. There was no head start for this seat. Sources came from the frame's candidate list and were extended where the candidates were thin. Five research agents (Sonnet) checked each source at its origin. Two of them were rerun after the first pass returned nothing. Opus curated the results into the rows below. Brandon's answers to the frame: no practice form is ruled out, and any trained member can run live practice. The AI presenter policy stays founder-gated.

## Status key

- **verified-primary**: the primary source was opened this build and supports the claims in the row. That means the full text, or the publisher or journal abstract page.
- **verified-secondary**: the primary could not be opened, and a reputable secondary source opened this build supports the claims.
- **partially-verified**: the source exists as cited, and the row names which claims rest on a weaker level.

No row is held from memory. Where a merged row mixes statuses, the row carries the lowest status and the Status cell names the weaker parts. Effect sizes appear in the evidence notes so the strength of each claim can be judged. The profile states direction, never the figure, per the standing rule on figures.
