# Ideate

Load: Curriculum & Program Architect, Learner Advocate, Hospitality Craft Educator (if live in the manifest; otherwise note its absence).

1. Read the intake and any related modules in the catalog.
2. With the Architect: write the transfer goal as an autonomous performance. Name the slot (introduce, reinforce, master), prerequisites, and any gate it feeds. Flag possible threshold concepts as hypotheses.
3. With the Learner Advocate: name the real learner and conditions (on a phone, before a shift, second language, cross-training veteran).
4. With the Hospitality Craft Educator: what the expert perceives, decides, and does; where the tacit knowledge sits; what cannot be learned from a screen. Anything back-of-house is chef-gated.
5. Offer at least three modality directions from `framework/modality-library.md` for the practice, one line each. Push past text, video, and multiple choice.
6. List known bindings and gated items.
7. Write `templates/01-concept-brief.md` into the module folder as `concept-brief.md`, create the folder from `templates/module/`, set status `concept` in both `module.md` and the catalog.

Re-ideating a parked module: move it back to `concept`, log why in `review-log.md`, keep the previous version in git history.

Commit: `ID concept: <transfer goal in a few words>`.
